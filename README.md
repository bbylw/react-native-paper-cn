 <p align="center"><i>React Native Paper 是一个跨平台的 UI 组件库，包含一系列可高度定制、可直接用于生产环境的组件，默认遵循并尊重 Google 的 Material Design 设计规范。</i></p>

## 快速开始

请参考[快速上手指南](https://callstack.github.io/react-native-paper/docs/guides/getting-started)了解使用说明。

## 文档

在我们的[文档](https://callstack.github.io/react-native-paper)中查看各个组件及其用法。

## 特性

- 遵循 [Material Design 设计规范](https://m3.material.io/get-started/)
- 同时支持 iOS 和 Android，并遵循 [平台适配规范](https://material.io/design/platform-guidance/cross-platform-adaptation.html)
- 完善的[主题定制支持](https://callstack.github.io/react-native-paper/docs/guides/theming)

## 上手体验

🧑‍💻 通过 [Expo](https://expo.dev/) 运行[示例应用](https://snack.expo.dev/@react-native-paper/react-native-paper-example_v5)，亲自感受它的效果。示例的源代码位于 [/example](https://github.com/callstack/react-native-paper/tree/main/example) 目录下。

📲 你也可以在两大应用商店的演示应用中试用各个组件：[Android](https://play.google.com/store/apps/details?id=com.callstack.reactnativepaperexample&hl=pl&gl=US) 和 [iOS](https://apps.apple.com/app/react-native-paper/id1548934513)。
